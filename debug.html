Арки — matrix3d corner-pin diagnostics
Диагностика текущей production-геометрии (совпадает с index.html). Source rectangle для homography каждой арки: X — bbox самой крупной connected component alpha-маски (реальное тело арки, без заголовка и без alpha-артефактов), Y — вся высота cropped-изображения (title+arch). Результат — matrix3d(...) применяется к единому PNG (заголовок+арка) без CSS perspective и без ручных left/top/rotate/scale. Данные пересчитываются compute_transforms.py → arch_transforms.json.
