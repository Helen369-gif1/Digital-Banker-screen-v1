Арки — matrix3d corner-pin
Каждая арка — это готовый обрезанный PNG (заголовок + арка = единый bbox, без прозрачных полей), посаженный в целевой угол сцены одной матрицей transform: matrix3d(...) (точный projective corner-pin: 4 угла источника → 4 угла назначения — без CSS perspective, как в эталонном файле). Откройте index.html в браузере; рядом должны лежать BACKGROUND.png, ШАБЛОН v1.png и папка cropped/ с 1–6.png.
